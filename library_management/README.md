# Day 6 – Library Management System (LLD)

## 📌 Problem Statement
Design a simple Library Management System that allows:
- Adding books and users
- Searching books
- Issuing and returning books

## 🧱 Classes Used
- **Book** – represents a book in the library
- **User** – represents a library member
- **Library** – manages books and users

## 🔄 Core Rules
- A book can be issued only if available
- A user can issue a maximum of 2 books
- Only issued books can be returned

## 🛠 Design Highlights
- Encapsulation of data
- Separation of responsibilities
- Uses STL containers (`unordered_map`, `vector`)
- Console-based simulation

## 🚀 Possible Extensions
- Fine calculation
- Admin role
- Due dates
- Book categories
- Persistent storage
